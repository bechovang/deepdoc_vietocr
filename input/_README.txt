Thu muc INPUT - copy file PDF (hoac anh) vao day
=================================================

Cach dung:
  1. Copy cac file PDF ban muon OCR vao thu muc nay.
  2. Chay "run.bat" (double-click hoac chay trong cmd).
  3. Ket qua TXT se nam trong thu muc "output".

Luu y:
  - Moi file PDF se ra 1 file .txt cung ten (cac trang duoc ghep lai,
    ngan cach bang dong "===== Trang N =====").
  - Cac dinh dang anh ho tro: .jpg, .jpeg, .png, .tif, .tiff, .bmp, .gif, .webp
  - File nay (_README.txt) chi de huong dan, co the xoa.

KHONG copy file vao cac thu muc con - chi de ngay trong "input/".
